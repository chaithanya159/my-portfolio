Case study: measuring a RAG chatbot

How a separate evaluation harness found a problem that the usual answer-quality score missed.

  1. The question

    A chatbot can give a fluent answer built from the wrong passages. Scoring only the answer hides that, so I wanted to score the retrieval too.

  2. The harness

    I wrote an evaluation harness that scores page hit rate, faithfulness, relevancy, and correctness against reference answers. A separate LLM acts as the judge.

  3. What it found

    It exposed a retrieval failure that faithfulness scores missed. Faithfulness checks that an answer sticks to the retrieved text, so it can’t tell you the retrieved text was the wrong text.

  4. The fix

    I tuned chunk size and overlap from 300/50 to 200/50. On the 15-question set, correctness rose from 0.93 to 1.00 and page hit rate from 0.85 to 0.92.

  5. The check

    On 10 hold-out questions, correctness was 0.90. That is the number to trust more, because the tuning set is small and those questions were kept apart from it.
